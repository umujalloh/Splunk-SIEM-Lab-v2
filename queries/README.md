# Queries

SPL queries from the BOTSv3 CoinMiner investigation, extracted from the main README into individual files.

## Contents

- `investigation/` — the 19 hunt queries from the investigation, numbered in the order they were run. Each one maps to a specific investigative question documented in the main README.
- `detections/` — three proposed detection rules built from the findings.

## File format

Each `.spl` file opens with a comment header documenting the purpose of the query, the phase it belongs to, and where to find it in the main README.
